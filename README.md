Одностраничное веб-приложение интернет-магазина с каталогом товаров и корзиной. Реализована клиентская маршрутизация, добавление и удаление товаров из корзины, изменение количества и автоматический подсчёт общей стоимости заказа без перезагрузки страницы.


[Live preview](https://shopping-cart-deploy-one.vercel.app/cart)


React, React Router, Context API, JavaScript, Vitest, HTML, CSS, Fake Store API, Fetch API
